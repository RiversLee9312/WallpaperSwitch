# Changelog

## 1.3.2 — 2026-10-18

- Release original project work under MIT and preserve original dependency terms.
- Add English/Chinese documentation, privacy/local-data information, and a
  versioned third-party license inventory with document SHA-256 hashes.
- Add About and an offline license viewer with asynchronous loading, progress
  indication, and pagination for long notices.
- Include project and component distribution terms in the installer.
- Remove obsolete, unused tray artwork.

- Make settings saves, previews, desktop changes, and startup checks asynchronous.
- Show loading indicators and guard repeated actions while work is pending.
- Retry tray registration and recover after taskbar recreation.
- Strengthen single-instance activation during background startup.
- Remove obsolete version 1.2 resource files during upgrade and fix startup with
  system-language/legacy settings.

## 1.3.0 — 2026-10-18

- Add MRT Core localization for 24 languages and a multilingual installer.
- Add opt-in high-priority startup through a Windows service.
