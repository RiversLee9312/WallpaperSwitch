# Upstream legal document sources

These original texts fill gaps where an MIT NuGet package declares its license
but omits a separate license file. They are copied without modifying their text.

- `H.NotifyIcon-LICENSE.md`: H.NotifyIcon/H.GeneratedIcons 2.3.2,
  https://github.com/HavenDV/H.NotifyIcon/blob/6b97277d084f68bcf60f08fcd769503e8e703bfa/LICENSE.md
- `dotnet-10-LICENSE.txt`: .NET runtime v10.0.0, used for the 10.0.0
  System.ServiceProcess.ServiceController and System.Diagnostics.EventLog packages,
  https://github.com/dotnet/runtime/blob/v10.0.0/LICENSE.TXT
- `Inno-Setup-LICENSE.txt`: copied from the Inno Setup 6.7.3 installation used to
  build this release, https://jrsoftware.org/files/is/license.txt

Other original texts are copied directly from the exact restored NuGet package
versions recorded in `Licenses/manifest.json`. The original file content is
preserved; the manifest records its SHA-256 hash and package source metadata.
